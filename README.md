# AttendX – Student Attendance Management System

A premium, fully-featured Student Attendance Management System built with HTML, CSS, and JavaScript.

## 🚀 Getting Started

1. Open the `student-attendance-system` folder
2. Double-click `index.html` to open it in your browser
3. Login with default credentials:
   - **Username:** `admin`
   - **Password:** `admin123`

## ✨ Features

| Feature | Description |
|---|---|
| 🔐 Login Page | Secure login with session management |
| 📊 Dashboard | Live stats, weekly trend chart, class-wise chart |
| 👨‍🎓 Students | Add, Edit, Delete students with search & filter |
| ✅ Attendance | Mark Present / Absent / Late per student per day |
| 📈 Reports | Per-student & per-class attendance summary + CSV export |
| ⚙️ Settings | Manage classes, change password, reset data |

## 📁 File Structure

```
student-attendance-system/
├── index.html   – Main HTML structure & all views
├── styles.css   – Complete design system (dark glassmorphism)
├── app.js       – All application logic
└── README.md    – This file
```

## 💡 Notes
- All data is stored in your browser's `localStorage`
- No backend or internet connection needed (Charts use CDN on first load)
- 20 sample students and 14 days of attendance data are pre-loaded
